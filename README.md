# lineage2-crow

## サイトの更新

ページの内容は `pages/` 内の Markdown ファイルを、サイトのレイアウトは `template.html` を編集してください。`main` にプッシュすると GitHub Actions が `scripts/build.py` で `index.html` を生成し、GitHub Pages に公開します。生成される `index.html` は直接編集しないでください。

初回のみ、GitHub リポジトリの Settings > Pages > Build and deployment で Source を「GitHub Actions」に設定してください。以後のビルド・公開状況は Actions タブで確認できます。
