# lineage2-crow

## レアアクセサリー情報の更新

レアアクセサリーの名前・カテゴリー・表の内容は `rare-accessories.md` を編集してください。`main` にプッシュすると GitHub Actions が Markdown から表示用HTMLを生成し、GitHub Pages に公開します。アクセサリーの内容を更新する際、`index.html` の生成対象部分を直接編集する必要はありません。

初回のみ、GitHub リポジトリの Settings > Pages > Build and deployment で Source を「GitHub Actions」に設定してください。以後のビルド・公開状況は Actions タブで確認できます。
