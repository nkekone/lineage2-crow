# ボス討伐戦

## 概要
毎日20:00より開催されるイベント。入場後の事前準備時間を経て、20:20から本格スタートします。

### タイムスケジュール・基本ルール
- **20:00** : オーク要塞戦開始と同時に画面右上にアイコン表示（ワープ可能）
- **20:00〜20:20** : 準備時間（雑魚モンスター出現。経験値多め・稀に精錬石[刻印]ドロップ）
- **20:20〜** : イベント本番スタート

与えたダメージ量に応じてリアルタイムでランキングが更新されます。<br>
・<strong>1位〜10位：</strong> キャラクターの頭上に順位が表示されます。<br>
・<strong>1位〜30位（最終）：</strong> <b>バーサーカースクロール 5個</b> がもらえます。

### 進行フロー（進行ゲージ）
右上のアイコンから詳細な進行状況（4本のゲージ）を確認できます。

| ゲージ | 進行イベント・出現モンスター |
| :--- | :--- |
| **1つ目のゲージ** | 準備段階（進行状況の目安） |
| **2つ目のゲージ** | 満タンになると <strong>中ボス①</strong> が登場。<br><small style="color: #666;">※確率でボスが「イスティナ」に確定する場合があります（イスティナ確定時は中ボスは登場しません）。</small> |
| **3つ目のゲージ** | 満タンになると <strong>中ボス②</strong> が登場。 |
| **4つ目のゲージ** | 満タンになると <strong>ボス</strong> が登場！ |

## 登場モンスター

### 雑魚モンスター
悪魔系モンスター登場。「闘争心」が付与されています。攻撃力は比較的弱めで経験値が多く、稀に **精錬石[刻印]** をドロップします。

### 中ボス①（2つ目のゲージ満タンで登場）
- **デュークエビル ヒテール** （右下の魔法陣）
- **エレメンタルキング ブエラ** （左下の魔法陣）
- **スコーピオンキング ブラス** （上/一番奥の魔法陣）

- 「闘争心」が付与されています。
- 一定量ダメージを与えると、経験値を取得できる **アーク** を獲得。
- とどめをさしたプレイヤーは、 **精錬石[刻印] 3個** をドロップ獲得できます。

### 中ボス②（3つ目のゲージ満タンで登場）
- **スケルトンキング ヒラーク** （右上の魔法陣）
- **リッパーキング ケスマ** （左上の魔法陣）

- 「闘争心」が付与されています。
- 一定量ダメージを与えると、経験値を取得できる **アーク** を獲得。
- とどめをさしたプレイヤーは、 **精錬石[刻印] 3個** を入手できます。

### ボス（4つ目のゲージ満タンで1体出現）
| ボス名 | 対応・注目ドロップアイテム |
| :--- | :--- |
| **闇の執行者 パーラー** | ドラゴンのベルト |
| **地下の使者 クルック** | 権能のタリスマン |
| **暗黒竜の巫女 ティアト** | ドラゴンのベルト |
| **捕らわれたヘルデーモン ハーフ** | 権能のタリスマン |
| **不滅の君主 エキムス** | ファントムマスク |
| **イスティナ** | ドラゴンの卵アガシオン |

- 一定量ダメージを与えると、 **経験値アーク** や **対応したアイテム** を取得できます。
- とどめをさしたプレイヤーは **祝福された防具強化スクロール** を入手できます。<br><small style="color: #e11d48;">※ヘルビートルが出現した場合、とどめ報酬の祝福された防具強化スクロールは入手できません。</small>

### 特殊ボス：ヘルビートル（ボス討伐時に確率出現）
ボス討伐後、一定確率で出現するボーナスボスです。<b>3分以内に倒す必要があります。</b>
- 一定量ダメージを与えると **黄金のメダル** を獲得。
- とどめをさしたプレイヤーは **祝福された防具強化スクロール** を入手。
- とどめをさしたプレイヤーは一定確率で **アデナポーチ** を入手できます。
