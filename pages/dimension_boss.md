# 次元の扉 ボス討伐

## 概要

Lv.85以上から参加できるデイリーミッション対象のボスコンテンツです。  
現在のクロウサーバーでは血盟による独占などはなく、誰でも自由に参加して討伐に挑戦できます。

---

## 基本仕様・参加ルール

| 項目 | 内容 |
| :--- | :--- |
| **推奨レベル** | **Lv.85以上**（デイリーミッション達成条件） |
| **参加権限** | 誰でも自由に参加可能（血盟独占なし） |
| **召喚場所** | **ギラン城の次元の扉** 前で召喚石を使用 |
| **Lv.85未満の参加** | デイリーはクリア不可ですが、**幸運賞・宝箱の獲得、およびアークモンスターの撃破（経験値獲得）が可能**です |

### ボス討伐後の追加出現（アークNPC）
ボス討伐成功時、その場に**アーク モンスター（アークNPC）が30個**出現します。

- **特徴:** 攻撃してこない光の玉状のNPCです。
- **討伐制限:** 攻撃してから**1分以内**に撃破すると経験値を獲得できます。（時間内に倒せなかった場合は消滅します）
- **アークNPC登場確率:**
  - **レッド アーク:** 20%
  - **パープル アーク:** 30%
  - **ブルー アーク:** 50%

## 出現ボスモンスター

召喚石使用時にランダムで出現するボスの一覧です。

| ボス名 | 特徴・注意点 |
| :--- | :--- |
| **コア** | プラズマを使用。一定時間行動不能になるが、ダメージはない。 |
| **オルフェン** | 麻痺攻撃を使用してくる。 |
| **クイーンアント** | 攻撃速度が低下するデバフ攻撃をしてくる。 |
| **ザケン** | 出血攻撃を使用。レベルが低いうちはダメージに注意。 |
| **ケルビム** | 召喚される石から状態異常を付与。遠距離にいると氷が落ちてきて大ダメージを受けるため、石に注意しつつ接近して攻撃する方がダメージを受けにくい。かなり硬い。 |
| **ヴルカン** | 攻撃力が高いプレイヤーを一定時間空中に吊り上げる。岩石を飛ばして一定時間地面で行動不能にする攻撃を使用。攻撃力・防御力ともに高く、出現ボスの中で最強。 |

## 報酬とデイリーミッション

討伐に参加することで、以下の報酬やミッション達成が狙えます。

### 1. デイリーミッション
- **対象ミッション:** 「次元の扉のボス討伐」
- **達成条件:** Lv.85以上のキャラクターでボス討伐に参加

### 2. 討伐報酬
- **幸運賞:** ボスへ一定量のダメージを与えたタイミングで獲得できます。（※Lv.85未満でも獲得可能）
- **宝箱:** ボスにラストアタック（とどめ）を刺したプレイヤーが獲得できます。（※Lv.85未満でも獲得可能）
- **アークNPC討伐:** 撃破すると経験値を獲得できます。（※Lv.85未満でも撃破・獲得可能）

#### 幸運賞の獲得アイテム一覧
- +4～+6プロテクション クローク ボックス
- +4～+6アデンのタリスマン ボックス
- +4～+6エヴァのタリスマン ボックス
- +4～+6迅速のタリスマン ボックス
- +4～+6権能のタリスマン ボックス
- +4～+6ドラゴンのベルト ボックス
- +4～+6英雄のサークレット ボックス
- +4～+6ファントム マスク ボックス
- +4～+6ドラゴンの卵アガシオン ボックス 刻印

## 次元の扉の召喚石の入手方法

召喚石はショップ等での販売はなく、特定の強敵にとどめを刺した際にごく稀にドロップ獲得できます。

1. **モンスター侵攻のリーダー**（とどめ撃破）
2. **オーク要塞のアマド**（とどめ撃破）

召喚石を手に入れたら、プレイヤー同士で声を掛け合ってギラン城の次元の扉で召喚してみましょう！
