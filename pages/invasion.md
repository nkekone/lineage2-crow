# モンスター侵攻

## 概要
リネ２時間の00:00に発生する。  
発生する場所はランダム。

### デイリーミッション
| ミッション名 | 達成条件 |
| :--- | :--- |
| **侵攻モンスターの討伐** | モンスター150体を倒す |
| **モンスターの進行阻止** | リーダーを倒す |
| **暗黒軍団のボス討伐** | リーダーを倒した後、ランダムに出現する暗黒軍団を倒す |

### 発生する場所と推奨レベル
| 推奨レベル | 発生する場所 |
| :--- | :--- |
| **Lv.90以上（要確認）** | 捨てられた炭鉱 |
| **88～90** | タイガ駐屯地 |
| **87～89** | 幻想の蜃気楼 |

---

### タイガ駐屯地、捨てられた炭鉱の概要

-  : 開始
-  : 指揮官1登場
-  : 指揮官2登場

- 02:30にリーダーが登場する

### 幻想の蜃気楼の概要
**タイムスケジュール**
-  : 開始
-  : リーダー出現

- 開始、リーダー出現時間は他と同様。
- 指揮官が４体（５体？）発生する。
- リーダーに一定ダメージ与えるごとに宝箱を入手出来る。

### 暗黒軍団の概要
- タイガ駐屯地、捨てられた炭鉱のリーダー討伐後にランダムで出現。
- リーダーに一定ダメージ与えるごとに宝箱を入手出来る。
- リーダーは最大２体出現する。
